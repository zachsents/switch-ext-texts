# spur-texts

Every text both ways, and sends that report delivered and read.

A [Switch](https://switch.ax) spur: a Python MCP server (`sbmcp.py`, a Switchboard appendage) that Switch runs through
[spur-kit](https://github.com/zachsents/spur-kit)'s shim. Its messages carry who sent them, for Switch's inbox and Contacts.

## Install

Ask Switch's agent to install `github:zachsents/spur-texts`, or add it in the desktop's Spurs view (⌘K, Spurs). Switch runs it
on the first machine with what it needs (`messages`).

## Setup

Runs on a Mac signed in to Messages, which must provide `messages`. Its process needs Full Disk Access to read Messages' database.
